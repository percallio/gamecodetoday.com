How to Redeem

1. Have the host start a session in Big Walk — the Join Code is visible in a corner of the host menu before the session begins. 2. Mid-session the host can reopen it via the in-game menu > Session Details, which is also where the session password is changed (v1.4.9+ requires a password for new games). 3. Players who are not platform friends join by entering the host's current code — not an old shared one — and the first two version-number sections must match on both devices (1.5.x and 1.6.x do not interop).
